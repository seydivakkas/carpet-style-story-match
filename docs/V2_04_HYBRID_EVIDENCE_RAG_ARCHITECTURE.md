# V2-04 — Hybrid Visual Evidence & Evidence RAG Architecture

## Overview

The V2-04 module establishes the **Deterministic Color Observation Engine**, **Source Research Engine**, and **Evidence RAG Foundation** for the Carpet Style & Story Match project.
It bridges verified visual motif subjects to authoritative, institutionally backed cultural evidence while guaranteeing **ABSOLUTE SAFETY AND PROVENANCE INVARIANTS**.

---

## 1. Frozen Hybrid Architecture

NO single LLM or VLM model owns the full pipeline. The system enforces strict separation of concerns across deterministic computer vision, reference visual verification, curator review gates, evidence retrieval, cultural claim validation, and story rendering:

```
IMAGE
  ↓
QUALITY / RECTIFICATION
  ↓
┌─────────────────────────────────────┐
│ VISUAL EVIDENCE (Deterministic CV)  │
│ - Style DNA (9D Engine)             │
│ - Color Observations (K-Means Lab)  │
│ - Reference VLM visual verification │
└──────────────────┬──────────────────┘
                   ↓
             MotifCandidate
                   ↓
              REVIEW GATE (Curator Confirmed / Verified Canonical)
                   ↓
             VERIFIED MOTIF (Canonical / Alias Resolver)
                   ↓

                   ↓
              EvidencePack (evidence-pack-v1.0.0)
                   ↓
             Claim Validator (V2-05)
                   ↓
            Story Presentation (V2-05)
```

## 2. Model Roles & System Boundaries

- **`Qwen/Qwen2.5-VL-3B-Instruct-AWQ`**: Function: **`REFERENCE_VISUAL_VERIFIER`**. It MUST NOT become a cultural reasoner, cultural knowledge base, or story generator.
- **Color Extraction Engine**: Function: **`ColorAnalysisService`**. Runs CIELAB K-Means clustering with perceptual color labels.
- **Evidence RAG Engine (V2-04)**: Function: **`SourceResearchProvider`**. Performs neutral academic query expansion, source tier filtering, chunking, locator traceability, and EvidencePack assembly.
- **Claim Validator & Story Curator (V2-05)**: Function: **`CulturalClaimValidator`** & **`StoryPresentationCurator`**. (Not implemented in V2-04).

## 3. Cultural & Material Safety Invariants

### 1. Visible Color Safety Rules
- **`VISIBLE COLOR != DYE MATERIAL`**: Visual RGB, HSV, or Lab color observations (e.g. `warm_red`, `indigo_like`) DO NOT establish dye material. `dye_material` is hard-coded and validated to be ALWAYS `"UNKNOWN"`.
- **`COLOR != CULTURAL MEANING`**: Static symbolic color rules (e.g. `red -> love`, `blue -> protection`, `green -> sacred`) are FORBIDDEN as deterministic outputs. Color observation contains zero symbolism.

### 2. Controlled Canonical Motif & Alias Resolution
- Free-text CLI or user strings MUST NOT become `VERIFIED_CANONICAL` merely because they resemble a motif.
- `resolve_canonical_motif_subject` resolves input through the controlled canonical set (`CANONICAL_MOTIFS`) or curated alias registry (`APPROVED_MOTIF_ALIASES`).
- Unknown input strings (e.g. `"magic-star"`) raise `ValueError("UNKNOWN_MOTIF")`.
- Unverified proposal states (`AI_CANDIDATE`, `UNMAPPED_MOTIF_CANDIDATE`, `ABSTAINED`) are strictly **BLOCKED** from triggering cultural research.

### 3. Neutral Query Expansion
- Queries generated by `ResearchQueryBuilder` (`cultural-research-query-v1.0.0`) MUST remain neutral.
- Visual taxonomy categories (e.g., `repeating_geometric`, `prayer_niche_like`) MUST NOT determine research culture.

## 4. Source Quality Tiers & SSRF Governance (`source-quality-policy-v1.0.0`)

| Source Tier | Description | Examples |
| :--- | :--- | :--- |
| **`TIER_1_PRIMARY_INSTITUTIONAL`** | Museums, government cultural institutions, university archives | MET Museum, V&A Museum, Louvre, Turkish Ministry of Culture |
| **`TIER_2_SCHOLARLY`** | Peer-reviewed journals, academic monographs, scholarly catalogues | Academic journals, university press publications |
| **`TIER_3_REPUTABLE_SECONDARY`** | Established cultural heritage reference works, encyclopedias | Cultural archives, heritage reference works |
| **`REJECTED_SOURCE`** | Unverified blogs, social media, commercial product/dealer sites | Pinterest, Etsy, eBay, commercial carpet seller sites (Merinos, Dinarsu) |

- **Product Source Separation**: Commercial carpet manufacturer product pages (e.g. Merinos, Dinarsu) are valid **Product Catalog** sources, but are strictly **REJECTED** as cultural symbolism evidence.
- **SSRF Safeguards**: `is_ssrf_safe_url` rejects loopback (`127.0.0.1`, `localhost`), cloud metadata (`169.254.169.254`), private IP ranges (`10.x`, `172.16-31.x`, `192.168.x`), and non-web schemes (`file://`, `ftp://`).

## 6. EvidencePack Schema Contract (`evidence-pack-v1.0.0`)

- **Mandatory Locators**: Every `EvidenceUnit` MUST specify a non-empty locator (page number, catalog entry, object ID, section heading).
- **Copyright Excerpts**: Excerpts are short and copyright-bounded (max <= 300 characters).
- **Forbidden Fields**: Top-level keys `final_claim`, `symbolic_meaning`, `story`, `cultural_truth`, and `narrative_prose` are **STRICTLY FORBIDDEN**.
- **Contradiction Detection**: Discrepancies across evidence sources produce `EvidenceConflict` records without auto-resolving winners in V2-04.
