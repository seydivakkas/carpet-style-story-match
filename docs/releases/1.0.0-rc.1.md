## 1. Product Summary

**Carpet Style & Story Match v1** is an explainable visual characterization, narrative affinity, and historical connection platform for textile arts and woven carpets.

Unlike black-box AI recommendation engines or speculative attribution systems, Carpet Style & Story Match operates on a strict **three-axis explainable architecture**:
1. **Visual Style Match**: Mathematical 9D Style DNA comparison between user visual preferences and carpet visual profiles.
2. **Narrative Affinity**: Explicit user narrative interest matching against source-backed motif story knowledge.
3. **Historical Connection**: Pairwise visual proximity comparison between catalog carpets and verified museum reference items.

Each axis is strictly independent and evaluated on its own domain semantics. The system does not combine these axes into a single "overall score", does not perform psychological user profiling, and does not assert historical authenticity or provenance based on visual similarity alone.

## 2. Three-Axis Architecture & Frozen Contracts

### Axis 1: Visual Style Match (`visual-style-match-v1`)
- **9D Style DNA Dimensions**:
  - `D1 color_energy`: Warm/vibrant vs cool/muted palette intensity.
  - `D2 color_diversity`: Palette hue diversity & richness.
  - `D3 contrast`: Luminance & color contrast dynamics.
  - `D4 warmth`: HSL warm hue balance (red/orange/yellow).
  - `D5 visual_complexity`: High-frequency spatial detail & entropy.
  - `D6 structural_order`: Grid/symmetry alignment & directional coherence.
  - `D7 rhythm_repetition`: Regular motif repetition & pattern periodicity.
  - `D8 focal_strength`: Salience & visual energy concentration.
  - `D9 form_language`: Curvilinear vs rectilinear/geometric form ratio.
- **Match Labels**: `VERY_STRONG` (≥90.0), `STRONG` (≥75.0), `MODERATE` (≥60.0), `LIMITED` (≥45.0), `LOW` (<45.0). Note: `WEAK` label is not part of the runtime contract.

### Axis 2: Narrative Affinity (`narrative-affinity-v1`)
- **8 Narrative Themes (N1..N8)**:
  - `N1 nature_growth`: Flora, garden, life renewal motifs.
  - `N2 belonging_home`: Domestic protection, sanctuary, tribal identity.
  - `N3 journey_discovery`: Path, pilgrimage, trade route motifs.
  - `N4 continuity_connection`: Interlocking lineage, endless knot motifs.
  - `N5 balance_order`: Cosmic symmetry, medallion order.
  - `N6 renewal_transformation`: Seasonal, bird, water motifs.
  - `N7 tradition_craft`: Weaving heritage, loom technique.
  - `N8 cultural_heritage`: Regional history, archive provenance.
- **Affinity Labels**: `VERY_STRONG`, `STRONG`, `MODERATE`, `LIMITED`, `NOT_AVAILABLE`. (Categorical only; no numeric product compatibility percentage).

### Axis 3: Historical Connection (`historical-connection-v1`)
- **Verified Reference Collection**: 12 verified museum/archive reference items (V&A, Metropolitan Museum of Art, Musée du Louvre, TIEM Istanbul, Al-Sabah Collection).
- **Proximity Labels**: `VERY_CLOSE`, `CLOSE`, `MODERATE`, `LIMITED`.
- **Disclaimer**: Visual similarity indicates aesthetic proximity only. It does not authenticate age, dynasty, workshop, or historical origin.

## 3. Operations & Operational Readiness

- **Database**: PostgreSQL 16.x with connection pool pre-ping and lifecycle disposal. Alembic migration head `014`.
- **Storage**: S3 / MinIO object storage factory with local filesystem fallback for development.
- **Probes**: `/health/live` (liveness, HTTP 200) and `/health/ready` (readiness, DB & storage check, HTTP 200/503).
- **Security & Logging**: Structured JSON logging, `X-Request-ID` correlation ID propagation, security headers (`nosniff`, `strict-origin-when-cross-origin`, `DENY`), and in-memory bounded rate limiting (HTTP 429).
- **Backup & Smoke**: Automated database backup script (`scripts/backup_postgres.py`) and production HTTP smoke test runner (`scripts/smoke_production.py`).

---

## 4. Known Limitations & Public Deployment Notice

1. **No User Authentication**: Version 1.0.0-rc.1 does not provide user authentication or RBAC. Public internet deployments must restrict access via API gateways, VPNs, or reverse proxies.
2. **Pairwise Visual Proximity**: Historical connections represent visual similarity only. The platform does not verify historical authenticity.
3. **No Automatic Recommendation Ranking**: The application presents explainable matches and catalog browsing without forced global ranking algorithms.
4. **Rate Limiting Scope**: Default rate limiter operates per container instance. Multi-node deployments require gateway-level rate limiting.
